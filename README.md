# JarvisAI v3.0

Voice-controlled Android assistant using Gemini API.

## Features
- Voice commands with "Jarvis" wake word
- Open apps, click, type, scroll
- Torch, volume, call control
- Web search
- English / Hindi / Gujarati voice
- Direct REST API (no deprecated SDK)

## Setup
1. Get Gemini API key: https://aistudio.google.com/apikey
2. Install APK from GitHub Actions artifacts
3. Open app, paste API key, save
4. Grant permissions (mic, camera)
5. Enable Accessibility Service in settings
6. Select voice language
7. Tap Start Jarvis
8. Say "Jarvis open YouTube"

## Commands
- "Jarvis open YouTube"
- "Jarvis scroll down"
- "Jarvis click Settings"
- "Jarvis torch on"
- "Jarvis volume up"
- "Jarvis search weather today"
